# 手选基准缩放-高度版

急用版 JSX。

## 用法

1. 在 Illustrator 中手动选中 1 个基准对象。
2. 运行脚本。
3. 在输入框里填写目标高度，默认 `1024` 按 `px/pt` 理解。
4. 脚本会找到该对象所属的最外层父组，并等比缩放整个父组。
5. 缩放后，基准对象的高度会尽量接近输入的目标高度。

## 静默规则

- 保留目标高度输入框。
- 不弹出成功提示。
- 条件不满足时直接返回。

## 支持的输入

- `1024`：按 `1024 px/pt` 处理。
- `1024px`
- `1024pt`
- `1024mm`
- `10cm`
- `4in`

## 当前限制

- 只处理单选。
- 多层组默认缩放最外层父组。
- 不自动识别灰色底框，用户选中的对象就是基准对象。
- 如果深层隔离模式导致父组无法变换，请退出隔离模式后再运行。
- 自动模式下优先调用 C++ 命令 `HGBasisScaleToHeight`；如果插件不可用，再回退到 JSX 原生 Action 路径。
