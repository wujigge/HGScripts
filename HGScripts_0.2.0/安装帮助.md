# HGScripts 安装帮助

版本：v0.2.0
更新日期：2026-05-02

## 插件名称

海哥的Adobe脚本管理器 / HGScripts

## 支持的软件

- Adobe Illustrator
- Adobe Photoshop
- Adobe InDesign

当前 Illustrator 是主线；Photoshop / InDesign 已加入基础支持，可以打开面板、按宿主隔离脚本目录，并运行对应测试脚本。

## 方法一：自动安装插件

1. 解压 `HGScripts_0.2.0.zip`。
2. 双击运行 `安装.bat`。
3. 等待提示 `Installation completed.`。
4. 重启 Illustrator / Photoshop / InDesign。
5. 打开 `窗口 > 扩展 > HGScripts`，英文界面一般是 `Window > Extensions > HGScripts`。

## 如果面板菜单没有出现

双击运行：

```text
Enable_CEP_Debug_Mode.bat
```

这个脚本只做一件事：给当前 Windows 用户写入 Adobe CEP 未签名扩展所需的 `PlayerDebugMode=1` 注册表项。

运行后请完全关闭并重新打开 Illustrator / Photoshop / InDesign。

## 方法二：手动安装

如果 `安装.bat` 无法运行，也可以手动安装。

Mac 用户请参考同目录下的 `Mac安装说明_未测试.md`。目前我没有 Mac 设备，这份说明和尚未测试的 `.command` 安装脚本都需要实机反馈。

### 1. 复制插件文件夹

把解压后的这个文件夹：

```text
HGScripts_0.2.0\HGScripts
```

复制到：

```text
%APPDATA%\Adobe\CEP\extensions
```

复制完成后，请确认 `HGScripts` 文件夹内能直接看到 `CSXS`、`assets`、`scripts`、`user_scripts`。

### 2. 开启 CEP 未签名扩展

推荐直接运行：

```text
Enable_CEP_Debug_Mode.bat
```

如果想完全手动设置，按 `Win + R`，输入 `regedit`，然后在 `HKEY_CURRENT_USER\Software\Adobe\CSXS.7` 到 `CSXS.15` 下新建或修改字符串值：

```text
名称：PlayerDebugMode
类型：REG_SZ
数值：1
```

### 3. 重启 Adobe 软件

关闭并重新打开 Illustrator / Photoshop / InDesign。

## 脚本目录

插件自带脚本按宿主分开放置：

```text
HGScripts\user_scripts\illustrator
HGScripts\user_scripts\photoshop
HGScripts\user_scripts\indesign
```

## 常见问题

### 自动安装和手动安装有什么区别？

`安装.bat` 只负责把 `HGScripts` 文件夹复制到 CEP 扩展目录。

`Enable_CEP_Debug_Mode.bat` 只负责写入 `PlayerDebugMode=1` 注册表项。

手动安装就是自己完成这两件事。

### 面板菜单没有出现

可以依次检查：

1. 插件文件夹路径是否正确。
2. 是否存在 `HGScripts\CSXS\manifest.xml`。
3. 是否运行过 `Enable_CEP_Debug_Mode.bat`，或手动设置了 `PlayerDebugMode=1`。
4. 是否完全重启了 Adobe 软件。
5. 当前 Adobe 软件是否支持 CEP 扩展菜单。

### 面板打开了，但看不到脚本

检查脚本是否放在当前宿主对应目录：

- Illustrator 看 `user_scripts\illustrator`
- Photoshop 看 `user_scripts\photoshop`
- InDesign 看 `user_scripts\indesign`
