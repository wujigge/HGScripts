# 复制选择对象到新画板.jsx 逻辑说明

## 脚本用途

在当前活动画板右侧新建一个同尺寸画板，并把当前选中对象复制到新画板的相同相对位置。

这个脚本适合快速制作系列画板、复制当前版式、准备不同 mask 版本或不同颜色方案。

## 使用流程

1. 打开 Illustrator 文档。
2. 激活参考画板。
3. 选中一个或多个需要复制的对象。
4. 运行脚本。
5. 脚本会在右侧创建同尺寸新画板，并复制选中对象到新画板相同位置。

## 代码运行逻辑

1. 如果没有打开文档，弹窗提示并停止。
2. 如果没有选中对象，弹窗提示并停止。
3. 获取当前活动画板的 `artboardRect`。
4. 计算当前画板宽度。
5. 在当前画板右侧 `20 pt` 位置创建同尺寸画板。
6. 复制当前选择对象。
7. 将副本整体向右平移 `画板宽度 + 20 pt`。
8. 切换到新画板。
9. 清空原选择。
10. 选中新复制出来的对象。

## 与旧版区别

旧版使用：

- `app.copy()`
- `pasteInPlace`

新版改用：

- `duplicate()`
- `translate()`

这样不会覆盖系统剪贴板，也不依赖 Illustrator 的粘贴命令状态，更稳定。

## 注意事项

- 脚本会新增画板。
- 脚本会复制当前选中对象。
- 新画板默认放在当前画板右侧，间距为 `20 pt`。
- 新画板名称会尝试使用原画板名称加 `_copy`。
- 如果复制某些特殊对象失败，脚本会跳过该对象。

## 适合场景

- 快速复制当前画板元素到新画板。
- 做系列设计稿。
- 制作不同颜色或不同 mask 版本。
- 保持对象相对画板位置不变地复制版式。
