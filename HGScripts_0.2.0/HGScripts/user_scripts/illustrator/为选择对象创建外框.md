# 为选择对象创建外框.jsx 逻辑说明

## 脚本用途

根据当前选中对象的整体可见范围，生成一个无填充、白色描边的外接矩形，并只选中新生成的矩形。

这个脚本适合快速生成对象外框、裁切参考框、遮罩辅助框或导出边界。

## 使用流程

1. 打开 Illustrator 文档。
2. 选中一个或多个对象。
3. 运行脚本。
4. 脚本会创建一个包住选中对象的白色描边矩形。
5. 原选择会被清空，新矩形会被选中。

## 代码运行逻辑

1. 如果没有打开文档，直接结束。
2. 如果没有选中对象，直接结束。
3. 遍历当前选择对象。
4. 优先读取每个对象的 `visibleBounds`。
5. 如果 `visibleBounds` 读取失败，尝试使用 `geometricBounds`。
6. 合并所有对象边界：
   - 最左
   - 最上
   - 最右
   - 最下
7. 根据合并后的边界创建矩形。
8. 设置矩形：
   - 名称：`Selection_Bounds_Rect`
   - 无填充
   - 白色描边
   - 描边宽度 `1 pt`
9. 清空原选择。
10. 选中新矩形。

## 注意事项

- 脚本使用 `visibleBounds`，更接近屏幕上看到的范围，通常会包含描边影响。
- 对带效果、阴影或复杂外观的对象，Illustrator 的 `visibleBounds` 可能仍然和真实视觉边界略有差异。
- 锁定或隐藏对象会被跳过。
- 生成的是一个普通矩形路径，不会和原对象编组。
- 如果需要几何边界版本，可以以后另做一个 `geometricBounds` 版本。

## 适合场景

- 给选中对象快速生成外接框。
- 为导出或裁切准备边界。
- 为 Octane mask 或遮罩贴图准备矩形参考区域。
- 给后续画板创建脚本提供对象范围。
