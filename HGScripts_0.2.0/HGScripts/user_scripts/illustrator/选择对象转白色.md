# 选择对象转白色.jsx 逻辑说明

## 脚本用途

把当前选中对象里已有的填充或描边改成白色。

脚本不会给没有填充的对象新增填充，也不会给没有描边的对象新增描边。填充和描边都为空的对象会被跳过。

## 使用流程

1. 打开 Illustrator 文档。
2. 选中需要变白的对象。
3. 运行脚本。
4. 脚本静默处理，不弹窗。

## 代码运行逻辑

1. 如果没有打开文档，直接结束。
2. 如果没有选中对象，直接结束。
3. 创建 RGB 白色 `255, 255, 255`。
4. 遍历当前选择对象。
5. 如果对象是组 `GroupItem`，递归处理组内对象。
6. 如果对象是复合路径 `CompoundPathItem`，递归处理内部路径。
7. 如果对象是文字 `TextFrame`，处理文字的字符属性：
   - 原本有填充色，就把填充色改成白色。
   - 原本有描边色，就把描边色改成白色。
8. 其它普通对象：
   - `filled === true` 时，把填充改成白色。
   - `stroked === true` 时，把描边改成白色。
9. 锁定、隐藏、图片、符号等无法安全改色的对象会被跳过或忽略。

## 注意事项

- 这是直接改色脚本，会修改当前选中对象。
- 脚本不会新增填充或描边，只修改对象已经存在的外观。
- 图片、嵌入图像、链接图像不会被改成白色。
- 如果文字内部存在多段不同字符样式，脚本会按 `textRange` 统一处理，复杂文字样式可能需要手动确认。
- 正式批量处理前，建议先在少量对象上测试一次效果。

## 适合场景

- 快速把选中的图形元素改成白色。
- 制作白色版图标、遮罩素材、反白素材。
- 批量处理组或复合路径里的矢量对象。
- 保留对象原有“是否有填充/是否有描边”的结构，只改变颜色。
