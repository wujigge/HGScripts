# 选择对象转黑色.jsx 逻辑说明

## 脚本用途

把当前选中对象里已有的填充或描边改成黑色。

脚本不会给没有填充的对象新增填充，也不会给没有描边的对象新增描边。填充和描边都为空的对象会被跳过。

## 使用流程

1. 打开 Illustrator 文档。
2. 选中需要变黑的对象。
3. 运行脚本。

## 执行逻辑

1. 检查当前是否有打开文档。
2. 检查当前是否有选择对象。
3. 创建 RGB 黑色 `0, 0, 0`。
4. 遍历当前选择对象。
5. 对组和复合路径递归处理。
6. 对普通对象：
   - 原本有填充色，就把填充色改成黑色。
   - 原本有描边色，就把描边色改成黑色。
7. 对文字对象：
   - `filled === true` 时，把填充改成黑色。
   - `stroked === true` 时，把描边改成黑色。

## 注意事项

- 脚本不会新增填充或描边，只修改对象已经存在的外观。
- 图片、嵌入图像、链接图像不会被改成黑色。
- 锁定或隐藏对象不会被处理。
- 脚本默认静默运行。

## 适合场景

- 快速把选中的图形元素改成黑色。
- 制作黑色版图标、遮罩素材、剪影素材。
- 配合白色脚本快速切换黑白 mask 区域。
- 保留对象原有“是否有填充/是否有描边”的结构，只改变颜色。
