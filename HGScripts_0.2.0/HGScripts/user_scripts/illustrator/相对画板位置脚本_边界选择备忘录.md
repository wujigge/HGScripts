# 相对画板位置脚本：边界选择备忘录

## 问题现象

在“应用相对画板位置到选择对象”后，如果把对象旋转 180 度，再次运行应用脚本，位置可能会轻微变化。

理论上，旋转 180 度不应该改变对象中心点。出现轻微漂移，通常不是用户操作问题，而是脚本使用的边界类型导致的。

## 原因

Illustrator JSX 常用两种边界：

- `visibleBounds`：可见外框，包含描边、部分外观效果等视觉边界。
- `geometricBounds`：几何外框，更接近对象本身的几何位置。

`visibleBounds` 会受以下因素影响：

- 描边粗细
- 描边端点
- 旋转后的外框重新计算
- 文字、组、复合路径的可见边界
- Illustrator 内部小数精度
- 外观效果或剪切蒙版

所以对象旋转后，即使中心点视觉上应该不变，`visibleBounds` 重新计算出来的中心点也可能有 0.x 像素或更小的偏差。脚本再次应用定位时，就会根据这个偏差移动对象，造成轻微漂移。

## 本次处理方法

保留两套脚本：

### 默认推荐：几何中心版

- `记录对象相对画板位置.jsx`
- `应用相对画板位置到选择对象.jsx`

特点：

- 使用 `geometricBounds`。
- 更接近 Illustrator 属性面板里的中心点逻辑。
- 更适合精准定位、重复应用、旋转后不漂移。
- 应用脚本增加 `0.01 pt` 容差，小于这个位移就不移动。

### 备用：视觉中心版

- `记录对象相对画板位置_视觉中心.jsx`
- `应用相对画板位置到选择对象_视觉中心.jsx`

特点：

- 使用 `visibleBounds`。
- 更接近肉眼看到的外框中心。
- 适合粗描边、特殊外观、视觉边界比几何边界更重要的场景。
- 同样增加 `0.01 pt` 容差。

## 以后遇到类似需求时先提醒

凡是写 Illustrator 定位、对齐、复制位置、相对画板位置、批量移动脚本时，需要先提醒用户选择边界逻辑：

1. 如果追求属性面板一致、旋转稳定、重复运行不漂移，优先用 `geometricBounds`。
2. 如果追求肉眼看到的外框位置，优先用 `visibleBounds`。
3. 如果对象有描边、阴影、外观效果、剪切蒙版，要提前说明两者可能不同。
4. 应用定位时建议加入微小容差，例如 `0.01 pt`，避免小数误差造成反复微移。

## 简短结论

默认写精准定位脚本时，先用 `geometricBounds`。只有用户明确要“按视觉外框中心”时，再用 `visibleBounds`。
