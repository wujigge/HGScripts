# 安装帮助

插件名称：海哥的Adobe脚本管理器 / HGScripts
版本：v0.1.0
更新日期：2026-04-30

## 适用软件

本版主要面向 Adobe Illustrator 使用。当前以 Windows 下的 Illustrator 2025 / 2026 为主要测试环境。

## 安装方法

1. 解压 `HGScripts_0.1.0.zip`。
2. 双击运行 `安装.bat`。
3. 安装完成后，重启 Illustrator。
4. 在 Illustrator 里打开：`窗口 > 扩展 > HGScripts / Haige Adobe Script Manager`。

## 安装位置

`安装.bat` 会把插件复制到这个目录：

```text
%APPDATA%\Adobe\CEP\extensions\HGScripts
```

在大多数 Windows 电脑上，它通常对应到：

```text
C:\Users\你的用户名\AppData\Roaming\Adobe\CEP\extensions\HGScripts
```

## 脚本位置

插件自带脚本放在插件目录里的：

```text
HGScripts\user_scripts
```

安装后完整路径通常是：

```text
%APPDATA%\Adobe\CEP\extensions\HGScripts\user_scripts
```

你可以把自己的 `.jsx` 或 `.js` 脚本放进这个文件夹，然后在面板里点击刷新。插件也支持添加其它脚本文件夹作为来源。

## 设置和运行数据

插件设置保存在：

```text
HGScripts\data\settings.json
```

一般不需要手动修改。如果设置异常，可以先关闭 Illustrator，再备份或删除这个文件，插件会在下次启动时重建默认设置。

## 更新方法

新版本可以继续运行新包里的 `安装.bat` 覆盖插件主体文件。安装脚本会尽量保留你现有的 `data/settings.json` 和 `user_scripts` 里的个人脚本。

建议更新前先关闭 Illustrator。

## 常见问题

### Illustrator 里找不到插件

- 确认已经运行 `安装.bat`。
- 确认插件目录已经出现在 `%APPDATA%\Adobe\CEP\extensions\HGScripts`。
- 重启 Illustrator。
- 如果仍然不显示，可能是 CEP 未签名扩展调试模式没有生效，可以重新运行一次 `安装.bat`。

### 脚本列表没有更新

- 点击面板里的“刷新”。
- 确认脚本文件扩展名是 `.jsx` 或 `.js`。
- 如果脚本放在其它文件夹，需要先在面板里添加该文件夹来源。
