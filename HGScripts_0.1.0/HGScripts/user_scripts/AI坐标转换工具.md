# AI坐标转换工具.jsx 逻辑说明

## 脚本用途

打开一个坐标转换工具面板，用于读取 Illustrator 选中对象的坐标、宽高、画板占比、UV、Octane 等参数。

这是坐标转换工具的另一个版本，功能比 `ai坐标转其它_gemini.jsx` 更完整一些，包含“计算选中”“生成报告”“自定义报告”等按钮。

## 使用流程

1. 打开 Illustrator 文档。
2. 选中一个对象。
3. 运行脚本。
4. 在弹出的面板中点击“计算选中”。
5. 查看 AI 坐标、画板比例、UV、OC 等结果。
6. 需要时点击“生成报告”或“自定义报告”。

## 代码运行逻辑

1. 创建 ScriptUI `palette` 面板。
2. 创建说明区域和多个参数区域：
   - 对象参数：X、Y、宽、高。
   - 比例关系：宽/高、高/宽、宽/画板、高/画板。
   - ABS & T2D。
   - UV & Octane。
3. 点击“计算选中”后，通过 `BridgeTalk` 执行 Illustrator 内部逻辑。
4. 检查文档和选择对象是否存在。
5. 获取当前活动画板。
6. 计算画板宽高。
7. 读取选中对象 `geometricBounds`。
8. 计算对象几何中心点。
9. 用 `convertCoordinate()` 转换为画板坐标。
10. 根据画板宽高计算：
    - 归一化坐标 `u/v`。
    - 对象宽高占画板比例。
    - T2D 坐标。
    - UV 坐标。
    - OC/Octane 坐标。
11. 把结果填入面板。
12. 生成报告时，在文档中新建文字组 `HG_REP`，写入对象名称、坐标、比例等信息。
13. 自定义报告用于按用户输入或内部模板生成指定内容。

## 注意事项

- 当前脚本中文 UI 已乱码，面板文字可能显示异常。
- 它会使用 `BridgeTalk`，从 CEP 面板内运行时不一定比普通 JSX 稳定。
- 报告功能会在文档中新增文字对象。
- 使用 `geometricBounds`，适合几何坐标，不一定包含描边/阴影等视觉外框。

## 适合场景

- 给 C4D/Octane/UV 流程提供坐标参数。
- 检查对象在画板中的相对位置。
- 输出对象参数报告。
