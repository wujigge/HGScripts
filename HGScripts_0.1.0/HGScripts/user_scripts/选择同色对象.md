# 选择同色对象.jsx 逻辑说明

## 脚本用途

根据 Illustrator 色板面板中当前选中的色板，在当前活动画板内选中所有使用相同颜色的对象。

这个脚本只负责选择对象，不修改颜色。适合在生成 mask、批量改色、检查色板使用范围之前做选区准备。

## 使用流程

1. 打开 Illustrator 文档。
2. 激活目标画板。
3. 在色板面板中选中一个色板。
4. 运行脚本。
5. 脚本会清空当前选择，并选中当前画板内同色对象。

## 处理范围

脚本只处理当前活动画板内对象。

判断规则是：对象的 `geometricBounds` 中心点在当前活动画板范围内，就视为当前画板对象。

这不是 Illustrator 官方的对象归属画板字段，而是为了避免误伤其它画板采用的稳定规则。

## 颜色匹配规则

对象的填充色或描边色任意一个与色板颜色匹配，就会被选中。

支持的颜色类型：

- `RGBColor`
- `CMYKColor`
- `GrayColor`
- `SpotColor`
- `GradientColor`

渐变颜色按 `gradient.name` 判断是否相同。也就是说，两个对象使用同一个渐变定义时，会被认为是同色。

暂不支持图案 `PatternColor`。

## 代码运行逻辑

1. 如果没有打开文档，弹窗提示并停止。
2. 读取色板面板中当前选中的色板。
3. 如果没有选中色板，弹窗提示并停止。
4. 把色板颜色转换成统一的颜色 key。
5. 获取当前活动画板范围。
6. 清空当前选择。
7. 遍历文档对象。
8. 递归处理组和复合路径。
9. 跳过锁定、隐藏、图片、符号对象。
10. 对当前画板内对象检查填充色和描边色。
11. 匹配色板颜色的对象加入结果。
12. 最后把结果对象设为选中。

## 注意事项

- 脚本不修改对象颜色，只改变选择状态。
- 运行前需要先在色板面板中选中一个色板。
- 如果对象跨画板，按中心点所在画板判断。
- 渐变按同名渐变定义判断，不按视觉相似度判断。
- 如果要直接生成黑白 mask，可以使用按取样色变白/变黑的脚本。

## 适合场景

- 快速选中当前画板里使用某个品牌色/专色的对象。
- 为 Octane mask 脚本准备选区。
- 检查某个色板在当前画板中的使用范围。
- 批量选中同色对象后再统一改色。
