# 选择转白其余转黑.jsx 逻辑说明

## 脚本用途

在当前活动画板内，把选中对象改成白色，把未选中对象改成黑色。

这个脚本适合快速生成当前画板的黑白分离效果、突出选中对象、制作遮罩预览。

## 处理范围

脚本只处理当前活动画板内的对象。

判断规则是：对象的 `geometricBounds` 中心点在当前活动画板范围内，就视为当前画板对象。

这不是 Illustrator 官方的“对象归属画板”定义，因为 Illustrator 对象本身没有固定的所属画板字段。这是脚本为了避免误伤其它画板而采用的稳定规则。

## 颜色规则

- 当前选择范围内的对象：已有填充或描边改成白色。
- 当前画板内未选中的对象：已有填充或描边改成黑色。
- 没有填充也没有描边的对象：跳过。
- 不新增填充。
- 不新增描边。

## 使用流程

1. 打开 Illustrator 文档。
2. 激活目标画板。
3. 选中需要保留为白色的对象。
4. 运行脚本。
5. 脚本静默执行，不弹窗。

## 代码运行逻辑

1. 如果没有打开文档，直接结束。
2. 如果没有选中对象，直接结束。
3. 获取当前活动画板的 `artboardRect`。
4. 递归收集当前选中对象：
   - 普通对象
   - 组内对象
   - 复合路径内对象
5. 把选中范围内可处理对象改成白色。
6. 建立选中对象映射，避免后续被改成黑色。
7. 遍历文档 `pageItems`。
8. 对组和复合路径递归处理。
9. 跳过锁定、隐藏、图片、符号对象。
10. 对未选中且中心点位于当前画板内的对象改成黑色。

## 注意事项

- 这是批量改色脚本，会修改当前画板内大量对象。
- 跨画板对象按中心点判断归属：中心点在哪个画板，就算哪个画板对象。
- 如果一个大对象覆盖当前画板但中心点在其它画板，脚本会跳过它。
- 复杂文字样式会按 `textRange` 统一处理，必要时手动检查。
- 正式批量使用前，建议先在副本或少量对象上测试。

## 适合场景

- 当前画板内快速生成黑白遮罩。
- 快速突出选中对象。
- 制作反白/剪影预览。
- 检查当前画板中哪些对象被选中、哪些对象未选中。
