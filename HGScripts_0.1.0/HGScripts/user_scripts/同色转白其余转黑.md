# 同色转白其余转黑.jsx 逻辑说明

## 脚本用途

在当前活动画板内，按第一个选中对象的颜色生成黑白 mask：

- 与取样颜色相同的填充或描边改成白色。
- 与取样颜色不同的填充或描边改成黑色。
- 没有填充或描边的对象跳过。

这个脚本主要用于从 Illustrator 版面中快速提取黑白遮罩图，方便后续作为 Octane 贴图 mask 使用。

## 取样规则

脚本读取第一个选中对象作为取样对象。

取样对象必须是单色对象或单色组：

- 普通对象：所有有效填充色和描边色必须相同。
- 组：递归检查组内所有有效填充色和描边色，必须全部相同。
- 复合路径：递归检查内部路径颜色，必须全部相同。

如果取样对象没有有效颜色，或包含多种颜色，脚本会弹窗提示并停止。

## 支持的取样颜色

- `RGBColor`
- `CMYKColor`
- `GrayColor`
- `SpotColor`
- `GradientColor`

渐变颜色按 `gradient.name` 判断是否相同。也就是说，两个对象使用同一个渐变定义时，会被认为是同色；如果只是视觉相似但不是同一个渐变定义，可能不会被认为相同。

暂不支持图案 `PatternColor` 作为取样颜色。

## 处理范围

脚本只处理当前活动画板内对象。

判断规则是：对象的 `geometricBounds` 中心点在当前活动画板范围内，就视为当前画板对象。

这不是 Illustrator 官方的对象归属画板字段，而是为了避免误伤其它画板采用的稳定规则。

## 改色规则

对当前活动画板内可处理对象：

- 有填充：
  - 填充色等于取样色，填充改白。
  - 填充色不等于取样色，填充改黑。
- 有描边：
  - 描边色等于取样色，描边改白。
  - 描边色不等于取样色，描边改黑。
- 没有填充：不新增填充。
- 没有描边：不新增描边。
- 填充和描边都没有：跳过。

## 使用流程

1. 打开 Illustrator 文档。
2. 激活目标画板。
3. 选中一个单色对象或单色组作为取样。
4. 运行脚本。
5. 脚本生成当前画板内的黑白 mask。

## 注意事项

- 这是批量改色脚本，会修改当前画板内大量对象。
- 取样对象必须是真正的单色对象或单色组。
- 渐变按同名渐变定义判断，不按视觉相似度判断。
- 图片、符号、锁定、隐藏对象会跳过。
- 正式批量处理前，建议先在副本或少量对象上测试。

## 适合场景

- 按某个颜色快速提取 Octane mask 白区。
- 从 Illustrator 版面里生成黑白材质遮罩。
- 检查某个颜色在当前画板中的分布。
- 把同色区域变白，其它有效外观变黑。
