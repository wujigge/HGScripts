# 当前画板创建黑色背景矩形.jsx 逻辑说明

## 脚本用途

在当前激活画板上创建一个和画板完全相同大小的矩形。

矩形默认设置为黑色填充、无描边，并发送到当前文档底层。

## 执行流程

1. 检查 Illustrator 是否已经打开文档。
2. 获取当前激活画板。
3. 读取当前画板的 `artboardRect` 坐标。
4. 按画板的左上角、宽度、高度创建矩形。
5. 设置矩形为 RGB 黑色填充。
6. 关闭描边。
7. 将矩形发送到底层。

## 注意事项

- 脚本只处理当前激活画板。
- 脚本不会改变已有对象。
- 如果当前文档里已经有其它背景矩形，脚本不会自动删除或合并。
- 适合配合黑白遮罩、Octane mask、导出透明/非透明底图等流程使用。
