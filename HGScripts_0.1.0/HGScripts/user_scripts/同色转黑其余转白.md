# 同色转黑其余转白.jsx 逻辑说明

## 脚本用途

在当前活动画板内，按第一个选中对象的颜色生成反向黑白 mask：

- 与取样颜色相同的填充或描边改成黑色。
- 与取样颜色不同的填充或描边改成白色。
- 没有填充或描边的对象跳过。

这个脚本是 `同色转白其余转黑.jsx` 的反向版本，主要用于从 Illustrator 版面中快速提取反向遮罩图。

## 取样规则

第一个选中对象作为取样对象。

- 普通对象：所有有效填充色和描边色必须相同。
- 组：递归检查组内所有有效填充色和描边色，必须全部相同。
- 如果取样对象没有可用填充或描边颜色，会弹窗提示。
- 如果取样对象包含多种颜色，会弹窗提示。

## 支持的颜色类型

- RGB
- CMYK
- Gray
- Spot
- Gradient

渐变颜色按 `gradient.name` 判断是否相同。

## 处理范围

- 只处理当前激活画板内的对象。
- 当前画板判断使用对象 `geometricBounds` 的中心点。
- 递归处理组和复合路径。
- 处理文字对象已有的填充和描边。
- 跳过图片、链接图、嵌入图、符号、锁定对象、隐藏对象。

## 改色规则

- 有填充：
  - 填充色等于取样色，填充改黑。
  - 填充色不等于取样色，填充改白。
- 有描边：
  - 描边色等于取样色，描边改黑。
  - 描边色不等于取样色，描边改白。
- 没有填充：不新增填充。
- 没有描边：不新增描边。
- 填充和描边都没有：跳过。

## 使用流程

1. 激活目标画板。
2. 选中一个单色对象或单色组作为取样对象。
3. 运行脚本。
4. 脚本检查取样对象是否为单色。
5. 脚本生成当前画板内的反向黑白 mask。

## 注意事项

- 如果对象跨越多个画板，只要中心点在当前画板内，就会被处理。
- 渐变只按渐变色板名称判断，不比较渐变角度、位置、缩放等外观参数。
- 不支持 Pattern 作为取样色。
- 这个脚本会直接改色，请在需要保留原稿时先复制文件或复制画板。

## 适合场景

- 按某个颜色快速生成反向 Octane mask。
- 让同色区域变黑，其它有效外观变白。
- 和 `同色转白其余转黑.jsx` 成对使用，快速切换 mask 黑白方向。
