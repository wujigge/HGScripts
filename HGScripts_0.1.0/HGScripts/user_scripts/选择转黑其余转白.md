# 选择转黑其余转白.jsx 逻辑说明

## 脚本用途

在当前活动画板内，把选中对象改成黑色，把未选中对象改成白色。

这个脚本是 `选择转白其余转黑.jsx` 的反向版本，适合快速生成反向黑白 mask。

## 处理范围

- 当前选择范围内的对象：已有填充或描边改成黑色。
- 当前画板内未选中的对象：已有填充或描边改成白色。
- 没有填充也没有描边的对象：跳过。
- 不新增填充。
- 不新增描边。
- 跳过图片、锁定对象、隐藏对象和符号对象。

## 使用流程

1. 打开 Illustrator 文档。
2. 激活需要处理的画板。
3. 选中需要保留为黑色的对象。
4. 运行脚本。

## 执行逻辑

1. 检查是否有打开文档。
2. 检查是否有选择对象。
3. 获取当前活动画板的 `artboardRect`。
4. 递归收集当前选择中的可处理对象。
5. 把选中范围内可处理对象改成黑色。
6. 建立选中对象映射，避免后续被改成白色。
7. 遍历文档对象。
8. 对组和复合路径递归处理。
9. 用对象中心点判断是否位于当前画板内。
10. 对未选中且中心点位于当前画板内的对象改成白色。

## 注意事项

- 当前画板判断使用对象 `geometricBounds` 的中心点。
- 如果对象跨越多个画板，只要中心点在当前画板内，就会被视为当前画板对象。
- 脚本不会处理图片本身。
- 脚本默认静默运行。

## 适合场景

- 当前画板内快速生成反向黑白遮罩。
- 让选中对象成为黑区，其它有效外观成为白区。
- 制作反向 mask、反向剪影预览。
