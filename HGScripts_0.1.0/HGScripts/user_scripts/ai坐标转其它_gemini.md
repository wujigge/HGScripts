# ai坐标转其它_gemini.jsx 逻辑说明

## 脚本用途

打开一个 ScriptUI 坐标转换面板，用于把 Illustrator 里选中对象的位置和尺寸转换成多种坐标参数，包括 AI 坐标、画板占比、ABS、T2D、UV、Octane 坐标等。

主要服务于把 Illustrator 里的设计位置转给其它软件或渲染流程，例如 Octane/C4D/UV 映射参考。

## 使用流程

1. 打开 Illustrator 文档。
2. 选中一个对象。
3. 运行脚本，弹出坐标转换面板。
4. 点击“计算当前对象坐标”。
5. 查看面板里的坐标和比例结果。
6. 如需输出到画板，点击“生成参数报告”。

## 代码运行逻辑

1. 创建 ScriptUI `palette` 浮动面板。
2. 在面板中创建多个区域：
   - 对象参数：X、Y、宽、高。
   - 比例关系：宽/高、高/宽、宽/画板、高/画板。
   - ABS & T2D 坐标。
   - UV & Octane 坐标。
3. 点击计算按钮后，通过 `BridgeTalk` 到 Illustrator 环境读取当前文档和当前选择对象。
4. 读取当前活动画板的 `artboardRect`。
5. 计算画板宽高。
6. 读取选中对象的 `geometricBounds`。
7. 用对象几何边界中心点计算对象中心。
8. 使用 `doc.convertCoordinate()` 把文档坐标转换为画板坐标。
9. 计算：
   - AI 坐标 X/Y。
   - 对象宽高。
   - 宽高比例。
   - 对象宽高占画板比例。
   - ABS 坐标。
   - T2D 坐标。
   - UV 坐标。
   - Octane 坐标。
10. 把结果回填到面板输入框。
11. 生成报告时，在画板上创建一个名为 `HG_REP` 的文字组，把参数写成多行文字。

## 注意事项

- 当前脚本中文 UI 已乱码，运行时面板文字可能不好读。
- 它是 ScriptUI 浮动面板，不是普通一次性脚本。
- 使用的是 `geometricBounds`，更适合几何位置，不一定等于视觉外框。
- 报告文字会写到当前文档里，会增加对象。
- 多个报告会根据已有 `HG_REP` 组做横向偏移。

## 适合场景

- 把 AI 里的对象位置换算给 Octane/C4D。
- 检查素材相对画板的比例位置。
- 生成对象参数报告给后续流程参考。
