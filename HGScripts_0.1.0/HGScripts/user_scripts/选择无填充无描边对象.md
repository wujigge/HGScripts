# 选择无填充无描边对象.jsx 逻辑说明

## 脚本用途

选中文档里填充和描边都为空的路径对象，用于清理隐藏的空对象。

脚本只选中，不删除，并且静默运行，不弹窗。

## 使用流程

1. 打开 Illustrator 文档。
2. 运行脚本。
3. 如果文档中存在填充和描边都为空的路径，脚本会把它们选中。
4. 你可以检查后手动删除。

## 代码运行逻辑

1. 检查是否打开文档。
2. 创建数组 `nullObjects`。
3. 定义递归函数 `checkObjects(items)`。
4. 遍历传入的对象集合。
5. 如果对象是 `GroupItem`，递归进入组内 `pageItems`。
6. 如果对象是 `CompoundPathItem`，递归进入内部 `pathItems`。
7. 如果对象是 `PathItem`，判断：
   - `filled === false`
   - `stroked === false`
8. 同时满足时，把对象加入结果数组。
9. 跳过锁定或隐藏对象。
10. 清空当前选择。
11. 如果找到空对象，就把文档选择设为这些对象。

## 注意事项

- 脚本只负责选中，不会自动删除，比较安全。
- 脚本静默运行，没有找到对象时不会弹窗。
- 会清空当前选择；如果找到空对象，则改为选中这些空对象。
- 适合运行后自己检查一眼再删除。
- 复合路径会检查内部 `pathItems`，比旧版直接判断复合路径本身更准确。
- 锁定和隐藏对象会跳过。

## 适合场景

- 清理从 PDF、CAD、模板文件导入后的空路径。
- 找出不显示但影响选择/导出的对象。
- 文件瘦身前检查无效对象。
