# HGScripts 安装帮助

版本：v0.3.0  
更新日期：2026-05-05

## 先装面板

1. 解压 `HGScripts_0.3.0.zip`。
2. 双击 `安装.bat`。
3. 看到 `Installation completed.` 就表示面板文件已经复制好了。
4. 重启 Illustrator / Photoshop / InDesign。
5. 在菜单里打开 `窗口 > 扩展 > HGScripts`。

如果菜单里没有 HGScripts，再双击：

```text
Enable_CEP_Debug_Mode.bat
```

运行后重新打开 Adobe 软件。

## 安装 Illustrator 加速插件

如果你主要用 Illustrator，建议再安装加速插件。

1. 关闭 Illustrator。
2. 右键 `安装Illustrator加速插件.bat`。
3. 选择“以管理员身份运行”。
4. 看到 `Installation completed.` 后，重新打开 Illustrator。

这个脚本会自动寻找电脑里的 Illustrator 版本，并把加速插件放到对应的插件文件夹里。

加速插件只支持 Windows Illustrator。没有安装加速插件时，HGScripts 仍然可以使用，只是部分脚本会自动走普通 JSX 方式。

## 手动安装面板

如果 `安装.bat` 不能运行，可以手动复制。

把解压后的 `HGScripts` 文件夹复制到：

```text
%APPDATA%\Adobe\CEP\extensions
```

复制完成后，`HGScripts` 文件夹内应能直接看到：

```text
CSXS
assets
scripts
user_scripts
```

## 手动安装 Illustrator 加速插件

把 `IllustratorPlugins_win` 文件夹里的 `.aip` 文件复制到 Illustrator 的插件目录。

常见位置类似：

```text
C:\Program Files\Adobe\Adobe Illustrator 2026\Plug-ins\HGScripts
C:\Program Files\Adobe\Adobe Illustrator 2025\Plug-ins\HGScripts
```

如果没有 `HGScripts` 文件夹，可以自己新建。

复制后请重启 Illustrator。

## 常见问题

### 面板菜单没有出现

1. 先运行 `Enable_CEP_Debug_Mode.bat`。
2. 完全关闭并重新打开 Adobe 软件。
3. 确认 `HGScripts` 文件夹内能直接看到 `CSXS`、`assets`、`scripts`、`user_scripts`。

### 加速脚本没有变快

1. 确认运行过 `安装Illustrator加速插件.bat`。
2. 确认安装后重启了 Illustrator。
3. 确认 HGScripts 面板顶部运行模式不是 `JSX`。

### 安装加速插件失败

请右键 `安装Illustrator加速插件.bat`，选择“以管理员身份运行”。
