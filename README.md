# HGScripts

当前版本：`v0.3.4`

本仓库只保留最新公开导出版本：

```text
HGScripts_0.3.4/
```

## 正式包

普通 Windows 用户优先下载：

```text
HGScripts_0.3.4/安装-海哥的Adobe脚本管理器v0.3.4.exe
HGScripts_0.3.4/海哥的Adobe脚本管理器v0.3.4-安装说明.txt
```

macOS 暂不支持。

## 内容

- `安装-海哥的Adobe脚本管理器v0.3.4.exe`：Windows 正式安装器。
- `海哥的Adobe脚本管理器v0.3.4-安装说明.txt`：Windows 安装说明。
- `cep/HGScripts`：CEP 面板源码和内置 JSX 脚本。
- `plugins/illustrator-win`：Windows Illustrator `.aip` 加速插件成品。
- `docs`：用户说明。
- `tools/windows`：Windows 辅助脚本。

## 安装

普通用户建议使用 Windows 安装器。本 GitHub 仓库同时保留公开源码、脚本和
`.aip` 成品，不再提供单独的 Windows 手动安装包。

## 公开边界

本仓库不包含 C++ 源码、Adobe SDK、Visual Studio 工程、调试符号、runtime 数据、
memory 数据、备份、本机状态或个人数据。
